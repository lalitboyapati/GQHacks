Read this first — no P&L exists yet

The event layer is complete and runs on real SEC data: 1,070 filings, classified, timestamped to the second, and committed so every judgement can be audited by hand. The trading layer is built and tested but has not been run on market data — it needs a Massive API key for prices and option chains.

So everything below is a finding about the opportunity set: how many tradable events exist, when they land, and which of the three ideas has enough observations to support a conclusion. No return, hit rate, or Sharpe figure appears on this page, because none has been computed. Two of these findings already change what you should expect from the strategies.

02

Timing works in your favour — 89% of filings land outside market hours

A filing accepted after the close or before the open gives a clean, unambiguous entry at the next session's open. Only a filing that lands mid-session forces the pessimistic assumption: entry at that day's close, because daily bars cannot honestly support a fill moments after it hit.

03

But the gap itself is not capturable

This is the single most important thing to understand about the results, and it follows directly from the finding above.

89%filed outside hours

When a filing lands pre-market or after the close, the price has already moved by the time you can trade. You buy at the gapped open. These strategies therefore trade post-gap drift — whether the reaction continues — not the initial reaction itself.

A put bought after a CEO-exit gap loses to implied-vol collapse and spreads unless the stock keeps falling. The MongoDB case that started this research is exactly the shape: the 8-K was accepted at 08:31 ET, an hour before the open, so the first tradable print already carried the news.

This is asserted directly in the test suite, which checks that the long put is profitable at −2%/session drift and unprofitable at +0.1%/session. Any result that appears to capture the gap indicates a timing bug, not an edge.

04

Departures are plentiful; genuinely forced exits are rare

Item 5.02 is filed far more often for routine board housekeeping than for a chief executive being removed. Separating the two is most of the work, and it leaves a healthy sample of senior exits but a very small one of dramatic ones.

05

The limiting finding: the cost-versus-savings test rests on ten filings

Idea 2 depends on comparing an upfront charge against the savings it is supposed to buy. Companies mostly do not disclose both.

10measurable filings

Ten observations across seven years and 86 issuers cannot support a statistical claim. A mean return over ten option trades is an anecdote with a decimal point, and the honest move is to say so rather than report it.

The verified extractions are real and correct — Wayfair's January 2024 cut ($80M charge, $50M savings, 1,650 roles, 13% of headcount), Upstart's $15M/$42M program, Macy's $1B plan. There simply are not enough of them.

The cheapest remedy was tried: the sweep was widened to catch restructurings announced under Reg FD (7.01) and Other Events (8.01) rather than only as cost disclosures. It added two observations — 10 to 12. Companies simply do not put savings figures in 8-Ks, and no item-code trick changes that.

What is left: extend the window before 2019, fall back to charge size and horizon instead of the ratio, or pull savings from the following 10-Q/10-K MD&A where they are actually quantified.

06

One filing in five is recycled disclosure

Idea 3 needed a way to tell a genuine revelation from a document that re-files Monday's press release on Thursday. Two independent signals agree on roughly the same fifth of the corpus — and that is before news data is even wired in.

07

How to run it

The event set is committed, so step 1 is optional — step 2 is where real P&L starts appearing.

Setup

# branch: 8kadv-test
cd gqh-8k-options-research
uv venv --python 3.11 && uv pip install -e .
cp .env.example .env     # add MASSIVE_API_KEY

1 · Build the event set (EDGAR only — no key needed)

python scripts/fetch_events.py --symbols MDB --start 2019-01-01
python scripts/fetch_events.py --universe default --start 2019-01-01
python scripts/describe_events.py # the numbers on this page

2 · Backtest it (needs MASSIVE_API_KEY)

python scripts/run_backtest.py --hold 5 --hold 10 --hold 21

# narrow the cut
python scripts/run_backtest.py --strategies exec_put,stock_short --max-cap 10e9
python scripts/run_backtest.py --spread-pct 0.08   # stress wider spreads

Results land in data/results/ as a trade-level CSV plus a per-strategy summary. The report pairs every mean with a t-statistic, a bootstrap confidence interval, hit rate, and the share of fills that came from real option bars — then flags any strategy with fewer than 8 trades, an interval spanning zero, or mostly modeled fills.

Every HTTP response is cached permanently, so a re-run of the committed event set is 3,430 cache hits and zero network calls. Set EIGHTK_OFFLINE=1 to turn a cache miss into an error and freeze a run.

08

What would make this conclusive

Ranked by how much each one currently limits the conclusions.

  1. Run it with the Massive key

    Everything downstream of event selection is built and tested but unexercised on market data. This is the one step between the current state and actual P&L.

  2. Find plan savings outside the 8-K

    Widening to Items 7.01 and 8.01 has been done and gained only two observations. The remaining routes are extending the window before 2019, or parsing the following 10-Q/10-K MD&A, where savings against restructuring charges are actually quantified.

  3. Calibrate the two scoring functions

    Novelty weights and executive-severity weights are hand-set priors. Once prices exist, regress them against realized abnormal returns instead of trusting the ordering.

  4. Validate fills on real OPRA quotes

    Massive gives daily option bars; the 4% half-spread is an assumption, and it is flat across names when small-cap spreads are much wider. Databento holds true bid/ask — reserved behind a hard cost guard, since the credit balance is finite.

  5. Correct for multiple testing

    Six strategies × three holding periods × several splits is roughly fifty comparisons. There is no family-wise adjustment yet, so nothing should be called significant until there is.

  6. Add an intraday path

    The 11% of filings that land mid-session are currently entered at the close. Minute bars would let them be entered near the filing timestamp and would sharpen the gap measurement for everything else.
